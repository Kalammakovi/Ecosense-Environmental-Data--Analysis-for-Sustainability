# Ecosense: Environmental Data Analysis for Sustainability

## Project Overview
Ecosense is a Power BI dashboard designed to analyze air quality and environmental data across different states and cities.

## Objectives
- Analyze Air Quality Index (AQI).
- Compare air quality across states and cities.
- Understand air quality status distribution.
- Explore average pollutant levels.
- Filter data using a state slicer.

## Tools Used
- Microsoft Power BI
- Data Analysis
- Data Visualization

## Dashboard Features
- Average AQI
- Total Monitoring Stations
- Total AQI Records
- Air Quality Status Distribution
- Average AQI by State
- Average AQI by City
- Average Pollutant Level
- Interactive State Slicer

## Project Outcome
This dashboard helps users explore air quality data, compare pollution levels, and understand environmental information through interactive visualizations.
